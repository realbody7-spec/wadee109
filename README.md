# ระบบคลังคู่มือ SOP ร้านอาหาร และตารางการแจ้งเตือนพนักงาน (Line & Messenger SOP Notifier)

ระบบจัดการ Standard Operating Procedure (SOP) ในร้านอาหาร พร้อมเชื่อมโยงระบบแจ้งเตือนกำหนดเวลาการปฏิบัติงานอัตโนมัติ ส่งข้อความรายละเอียดภารกิจไปยังกลุ่มทำงานผ่าน **LINE Notify**, **LINE Messaging API (Push)** และ **Facebook Messenger (Meta Send API)**

โปรเจกต์นี้แบ่งออกเป็น 2 ส่วนหลัก:
1. **Backend (Node.js/Express)**: ตรวจจับรอบเวลาแจ้งเตือนด้วย `node-cron` บันทึกข้อมูลแบบไร้รอยต่อในเครื่องด้วยรูปแบบ JSON และควบคุมพอร์ตสำหรับการทดสอบ API ยิงข้อความจริง พร้อมป้อนสัญญาณ Live Logs แบบ Real-time ผ่าน Server-Sent Events (SSE)
2. **Frontend (React/Vite)**: หน้าต่าง Dashboard สุดพรีเมียม สไตล์กลาสมอร์ฟิสซึม (Glassmorphism) มีปุ่มทดสอบยิงด่วน, ระบบสร้าง/แก้ไข SOP และกำหนดเป้าหมายภารกิจ, รวมถึงหน้าเชื่อมต่อ Tokens เพื่อความปลอดภัย

---

## 🚀 วิธีการทดสอบและรันระบบในเครื่องของคุณ

### 1. การติดตั้ง Dependencies ของเซิร์ฟเวอร์
กรุณาเปิด Terminal และติดตั้ง Library ต่างๆ ของโปรเจกต์ ทั้งในฝั่ง backend และ frontend:

**ติดตั้งในโฟลเดอร์ Backend:**
```bash
cd backend
npm install
```

**ติดตั้งในโฟลเดอร์ Frontend:**
```bash
cd ../frontend
npm install
```

### 2. การสั่งรันเซิร์ฟเวอร์ (พัฒนาเครื่องคอมพิวเตอร์เฉพาะส่วน)

**สั่งเริ่มทำงาน Backend (รันที่พอร์ต 5000):**
```bash
cd backend
npm run dev
```

**สั่งเริ่มทำงาน Frontend (รันที่พอร์ต 5173):**
```bash
cd frontend
npm run dev
```
หลังจากรันแล้ว ให้คลิกลิงก์เพื่อเปิดเบราว์เซอร์เข้าที่: **`http://localhost:5173/`**

## 🛠️ โหมดการทำงาน 2 รูปแบบ

### A. โหมดจำลอง (Simulation Mode - เปิดเป็นค่าเริ่มต้น)
* **จุดประสงค์**: เหมาะสำหรับการทดสอบระบบทันทีโดยไม่ต้องไปออก Token หรือสมัครบัญชีนักพัฒนา
* **การทำงาน**: เมื่อถึงรอบกำหนดเวลาบอร์ดแจ้งเตือนทำงาน ระบบจะไม่ยิงหา Line หรือ Messenger จริง แต่จะส่งสัญญาณความคืบหน้ามาแสดงที่หน้า **"คอนโซลล็อกยิงแชท" (Live Logs Console)** บนเว็บไซต์แบบวินาทีต่อวินาทีทันที

### B. โหมดใช้งานจริง (Production Mode)
คุณสามารถนำ Tokens ต่างๆ มากรอกในหน้า **"การเชื่อมต่อระบบ" (Integrations)** และปิด "โหมดจำลอง" ดังนี้:

#### 1. การเชื่อมต่อ LINE Notify (แนะนำที่สุด - ทำง่ายและฟรี)
1. ไปที่เว็บไซต์ [LINE Notify Bot](https://notify-bot.line.me/en/) ลงชื่อเข้าใช้ด้วยบัญชีไลน์ของคุณ
2. เข้าไปที่หน้าส่วนตัว (My Page) และคลิกปุ่ม **"Generate token"**
3. ตั้งชื่อหัวข้อข้อความ (เช่น *บอร์ดตรวจงาน FOH*) และเลือกกลุ่มไลน์ที่ต้องการส่งข้อความ
4. คัดลอก Token นำมากรอกลงหน้าตั้งค่าบนเว็บแอป
5. เชิญบอท **"LINE Notify"** เข้าร่วมกลุ่มไลน์ที่เลือกไว้ เพื่อให้บอทเริ่มส่งข้อความได้

#### 2. การเชื่อมต่อ LINE Messaging API (Push message)
1. เข้าไปสมัครเป็นนักพัฒนาที่ [LINE Developers Console](https://developers.line.biz/)
2. สร้าง Provider และสร้าง Channel ประเภท Messaging API
3. ไปที่แท็บ Messaging API เลื่อนลงมาเพื่อคลิก Issue ช่อง **Channel Access Token (v2.1)**
4. ค้นหา User ID ของคุณที่ล่างสุดหน้าคอนโซล (หรือสร้างบอทรับ Webhook เพื่อหา Group ID)
5. นำ Token และ ID กรอกลงที่หน้าระบบ

#### 3. การเชื่อมต่อ Facebook Messenger
1. สมัครบัญชีนักพัฒนาที่ [Meta Developers](https://developers.facebook.com/)
2. สร้างแอปพลิเคชันขึ้นมาใหม่ และเพิ่มผลิตภัณฑ์ **Messenger** ลงในแอป
3. เชื่อมโยงเพจ Facebook ของร้านอาหารของคุณ และรับ **Page Access Token**
4. รับรหัส **Page-Scoped User ID (PSID)** ของพนักงานที่คุณต้องการส่งข้อความหา
5. นำกรอกลงฟอร์มและสั่งบันทึกการตั้งค่า
